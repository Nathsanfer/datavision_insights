# 📊 CTI Insights

Sistema web desenvolvido para transformar dados comerciais da **CTI Comunicação de Dados e Tecnologia LTDA** em informações organizadas e insights estratégicos.

O projeto recebe uma planilha Excel com dados dos clientes, realiza o tratamento e padronização das informações, armazena os dados em banco de dados e apresenta os resultados por meio de dashboards interativos.

## 🎯 Objetivo

Facilitar a análise da carteira de clientes da CTI, reduzindo o trabalho manual e permitindo visualizar informações como:

* Distribuição de clientes por segmento;
* Classificação dos clientes nos níveis A, B e C;
* Faixas de faturamento;
* Serviços contratados;
* Relações e padrões entre os dados;
* Insights estratégicos para apoio à análise comercial.

## 🚀 Funcionalidades

* Upload de planilhas Excel;
* Validação e tratamento dos dados;
* Padronização automática das informações;
* Armazenamento dos dados em banco de dados;
* API REST para comunicação entre Front-end e Back-end;
* Dashboard com indicadores e gráficos;
* Análises estatísticas e geração de insights;
* Visualização responsiva.

## 🛠️ Tecnologias

**Front-end**

* Vue 3
* Tailwind CSS
* Chart.js
* Axios

**Back-end**

* Java
* Spring Boot
* Spring Data JPA
* API REST

**Dados**

* Python
* Pandas
* PostgreSQL

**Cloud**

* Vercel — Front-end
* Render — Back-end
* Neon — Banco de dados

## 🔄 Fluxo da aplicação

```text
Planilha Excel
      ↓
Upload e validação
      ↓
Tratamento e padronização
      ↓
API REST
      ↓
Banco de dados PostgreSQL
      ↓
Análise dos dados
      ↓
Dashboard
      ↓
Insights estratégicos
```
